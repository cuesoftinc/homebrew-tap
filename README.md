# Cuesoft Homebrew Tap

Homebrew casks for Cuesoft apps.

```sh
brew install --cask cuesoftinc/tap/cueprise
```

| Cask | App |
| --- | --- |
| `cueprise` | Cueprise desktop app for tills and their devices |

Each version's app files are attached to this repository's releases, tagged `<cask>-v<version>`.
